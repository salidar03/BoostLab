# BoostLab

Программа для Windows, которая готовит компьютер к играм: чистит мусор, включает игровые настройки Windows, следит за драйверами, делает резервные копии системы и убирает сетевой джиттер в Counter-Strike 2.

## Скачать

Последняя версия — в разделе [Releases](../../releases/latest): файл **BoostLab-Setup.exe**.

Установленный BoostLab сам проверяет новые версии при запуске, скачивает их в фоне и ставит при закрытии программы. Каждый файл сверяется по SHA-256, прежде чем установиться.

## Что умеет

- **Очистка** — временные файлы, кэш обновлений, отчёты об ошибках, кэш браузеров.
- **Производительность** — схема питания, игровой режим, планирование GPU, отключение лишних фоновых служб. Любую настройку можно вернуть.
- **Автозагрузка** — включение и выключение программ при старте Windows.
- **Драйверы** — пометки «новый / актуальный / устарел», поиск обновлений через Windows Update и NVIDIA.
- **Резервная копия** — точки восстановления и полный образ системы.
- **Counter-Strike 2** — диагностика джиттера, параметры запуска, графика под FPS, чёткость текстур.
- **Сеть** — пинг до серверов Valve, мониторинг соединения, выбор быстрого DNS.

## Требования

Windows 10 или 11 (64 бит). Программа просит права администратора — без них нельзя менять настройки системы.

Файл не подписан цифровой подписью, поэтому Windows при первом запуске покажет «Windows защитил ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
